# Dr. Harsha Narayanamurthy — Next.js site

This is the Next.js migration of the existing React/Vite personal-brand site.

## Run

1. Install Node.js 20+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Next.js.

## Production

`npm run build` then `npm start`.

## Deploy

Recommended: Vercel. Connect `drharshanarayanamurthy.com` as the primary domain and redirect `drharshanarayanamurthy.in` to it.

## Content verification

Before launch, verify all qualifications, experience figures, hospital affiliations, appointment URLs, media links and clinical claims with Dr. Harsha.
